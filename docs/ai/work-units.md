# 백엔드 작업 단위 진행표

원칙: 기존에 제안한 28개 단위를 순서대로 한 번에 하나 수행하고 결과를 보고한다.
앞선 MVP 구현이 있어도 각 단위의 요구사항을 다시 확인한 뒤 완료 처리한다.
완료는 해당 단위 범위의 완료이며 전체 서비스 운영 준비 완료를 의미하지 않는다.
